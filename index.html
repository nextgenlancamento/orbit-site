Projeto de integração Pix

Uma base para conectar sua campanha a um provedor Pix.

Este repositório contém uma API em PHP para criar cobranças, consultar pagamentos e receber notificações. Esta página apresenta o projeto; ela não processa pagamentos.

Pagamentos ainda não estão habilitados neste site. A API exige hospedagem com PHP e PostgreSQL, configuração segura das credenciais e adaptação ao provedor Pix escolhido. A Vercel não executa estes arquivos PHP como backend.

Verificação de saúde

Informa se o backend PHP e as configurações necessárias estão disponíveis.

GET /api/health.php

Criar cobrança

Recebe os dados da participação e solicita uma cobrança ao provedor configurado.

POST /api/create-charge.php

Consultar pagamento

Consulta o status da cobrança pelo identificador da transação.

GET /api/pix-status.php?txid=IDENTIFICADOR

Notificação do provedor

Recebe o webhook e confirma o estado consultando o provedor Pix.

POST /api/pix-webhook.php

Para colocar a API em funcionamento

Hospede o backend em um servidor com PHP 8.1+, cURL, PDO PostgreSQL e banco PostgreSQL. Configure as variáveis de ambiente no servidor, execute o schema SQL e ajuste os caminhos e formatos conforme a documentação oficial do seu provedor. Nunca exponha credenciais no frontend ou no repositório.

O código genérico deste projeto não deve ser considerado uma integração Pix pronta para produção até ser configurado e testado com o provedor real.
